# Project Name: Movie Recommendation System

## Features:
- User Registration/Login
- Movie Search
- Watchlist
- Reviews

## Technologies Used:
- PHP, MySQL, HTML, CSS, JavaScript
- AWS EC2
- GitHub
- Jenkins

## How to Run:
1. Install XAMPP
2. Place the project folder in `htdocs`
3. Start Apache & MySQL in XAMPP Control Panel
4. Import `database.sql` into phpMyAdmin
5. Open browser and go to `http://localhost/CineSphere-Agile`
